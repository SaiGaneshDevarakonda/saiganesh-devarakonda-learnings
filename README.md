## How each topic folder is organised
```
 01_Topic_Name/
 ├── README.md    ← Theory (diagrams, animations) + Practice Questions + Interview One-liner
 ├── quiz.md      ← multiple-choice quiz, questions only, with a link to its answer sheet
 ├── answers.md   ← quiz answer key + solutions to the practice questions
 └── assets/      ← animation GIFs (play on GitHub) + .html interactive versions (open in a browser)
```
**How to study:** read the README, try the practice questions without looking, take the quiz, then check answers.md.
